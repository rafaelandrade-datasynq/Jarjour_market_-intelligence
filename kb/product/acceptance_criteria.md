# Acceptance Criteria

- Django app runs locally with SQLite.
- Django Ninja exposes health, listings, search runs, summary, demo and export endpoints.
- Dashboard opens at `/dashboard/`.
- Dashboard uses executive Jarjour language and preserves visibility cards for collected, normalized, raw without normalization, reliable, review, incomplete and opportunities.
- Dashboard must not look like a technical scraping tool and must not add unnecessary charts.
- Demo data creates raw and normalized records.
- Carol Excel export contains the contracted tabs and headers.
- Tests cover health, demo creation, models, summary, export headers and raw data visibility.
- `make verify` passes before handoff.
