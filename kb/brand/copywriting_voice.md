# Copywriting Voice

Use human executive language:

- "Anúncios coletados"
- "Confiáveis"
- "Para revisar"
- "Oportunidades"
- "Resumo da coleta"
- "Leitura executiva do mercado"
- "Pesquisa imobiliária com rastreabilidade"
- "Oportunidades com base em dados"
- "Dados coletados, classificados e preservados"

Avoid exposing implementation terms such as scraper, parser, JSON payload or validation engine in the main UI.

Prefer short, confident sentences. The tone should be calm, institutional and useful for Carol's business workflow.

Never soften or remove visibility language for aesthetics. If raw items are not normalized, the UI must say so plainly.
